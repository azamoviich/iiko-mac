<h3 align="center">iikoOffice и iikoChain не делали для Mac.<br>Здесь они всё равно работают.</h3>

---

```bash
zsh -c "$(curl -fsSL https://raw.githubusercontent.com/azamoviich/iiko-mac/main/install.sh)"
```

Вставьте в **Терминал**. Введите версию iiko. Выберите iikoOffice, iikoChain или оба. Подождите 10–20 минут.

Когда появится `Done`, откройте `~/Applications` и запускайте **iikoOffice** или **iikoChain** как обычное приложение Mac.

## Зачем

Единственный «официальный» способ работать с iiko BackOffice на Mac — виртуальная машина с Windows: платный Parallels, лицензия Windows, 50–70 ГБ диска и вторая операционная система в памяти ради одного окна.

`iiko-mac` запускает **оригинальный, неизменённый** BackOffice прямо в macOS через [Wine](https://www.winehq.org/) — это слой совместимости, а не эмулятор. Без Windows. Без виртуальной машины.

| | Виртуальная машина | **iiko-mac** |
|---|---|---|
| Диск | 50–70 ГБ | **~3 ГБ** одно приложение, **~4 ГБ** оба |
| Память | целая вторая ОС | только сам iiko |
| Цена | Parallels + Windows | **бесплатно** |
| Установка | полдня | **одна команда, 10–20 минут** |

## Что получаете

- **Настоящее приложение.** Те же файлы, что iiko выпускает для Windows, с сервера самого iiko. Любая версия: вводите номер — установщик скачивает.
- **Ведёт себя как Mac-приложение.** <kbd>⌘C</kbd> <kbd>⌘V</kbd> <kbd>⌘A</kbd> <kbd>⌘Z</kbd> работают. Обычные `.app`, можно перетащить в Dock.
- **Экспорт в Excel работает.** Отчёты открываются в Excel или Numbers на Mac, PDF — в «Просмотре».
- **Ничего не нужно ставить заранее.** Ни Homebrew, ни Xcode.
- **Чисто.** Всё лежит в `~/iiko-mac`. Удаляется одной командой.

## Установка

1. Откройте **Терминал** (<kbd>⌘</kbd>+<kbd>Пробел</kbd> → `Терминал` → <kbd>Enter</kbd>).
2. Вставьте команду и нажмите <kbd>Enter</kbd>:

   ```bash
   zsh -c "$(curl -fsSL https://raw.githubusercontent.com/azamoviich/iiko-mac/main/install.sh)"
   ```
3. Введите версию iiko, например `9.2.7014.0`.
4. Выберите: `1` iikoOffice, `2` iikoChain, `3` оба.
5. Ждите строку `Done`. Терминал не закрывайте. Установка .NET идёт несколько минут без вывода — это нормально.
6. Finder → <kbd>⌘</kbd><kbd>⇧</kbd><kbd>G</kbd> → `~/Applications` → запустите приложение.
7. В окне входа нажмите **Дополнительно >>**, введите адрес и порт сервера, затем логин и пароль.

> [!IMPORTANT]
> Версия BackOffice должна **точно** совпадать с версией вашего сервера iiko, иначе сервер не пустит. Уточните у администратора iiko.

**Сервер обновили?** Запустите установщик ещё раз с новой версией. Wine и .NET останутся, скачаются только файлы iiko.

**Удаление:**

```bash
zsh -c "$(curl -fsSL https://raw.githubusercontent.com/azamoviich/iiko-mac/main/uninstall.sh)"
```

## Вопросы

**Медленно?**
Первый запуск 20–40 секунд. Дальше — обычная скорость.

**Мои данные в безопасности?**
BackOffice подключается напрямую к вашему серверу iiko, как и на Windows. Ничего не перехватывается и никуда не отправляется. `install.sh` — около 200 строк, можно прочитать.

**Куда сохраняются выгруженные файлы?**
`~/iiko-mac/prefix/drive_c/users/<вы>/AppData/Local/Temp/Resto/` — и открываются автоматически.

**iikoFront (касса)?**
Нет. Ему нужны драйверы кассового оборудования под настоящую Windows.

Как это устроено внутри и какие четыре проблемы пришлось обойти — в [английском README](README.md#how-it-works).

## Правовая информация

В репозитории **только скрипты установки**. Здесь нет программ iiko и нет программ Microsoft. При установке ваш Mac сам скачивает каждый компонент у его владельца, на условиях его лицензии: Wine — [Gcenx/macOS_Wine_builds](https://github.com/Gcenx/macOS_Wine_builds), .NET Framework — microsoft.com, iiko BackOffice — downloads.iiko.online.

Нужны собственная лицензия и сервер iiko. **Проект не связан с iiko и не одобрен ею.** «iiko», «iikoOffice» и «iikoChain» — товарные знаки их владельца, упоминаются только для описания совместимости. Предоставляется как есть, без гарантий. Скрипты распространяются по лицензии [MIT](LICENSE).
